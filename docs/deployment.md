# CareerVault Deployment Guide

## Overview

This guide outlines deployment of CareerVault using the infrastructure named in the project README:
- **Frontend:** Vercel
- **Backend:** Render
- **Database:** MongoDB Atlas
- **Authentication:** Firebase Auth

Deployment is listed as a **remaining task** in the project status, so some steps include `TODO` placeholders pending finalized configuration.

## 4. Frontend Deployment (Vercel)

### 4.1 Build Configuration
1. Connect the `frontend/` directory as the project root in Vercel.
2. Framework preset: Vite.
3. Build command: `npm run build`
4. Output directory: `dist` (Vite default).

### 4.2 Environment Variables
Set in the Vercel dashboard:
```
VITE_API_BASE_URL=<production Render backend URL>/api/v1
VITE_FIREBASE_API_KEY=<production key>
VITE_FIREBASE_AUTH_DOMAIN=<production domain>
VITE_FIREBASE_PROJECT_ID=<production project id>
```

### 4.3 SPA Routing
- Since the app uses React Router 6, configure Vercel to redirect all routes to `index.html` for client-side routing (Vercel typically handles this automatically for Vite/SPA projects — TODO: confirm if a custom `vercel.json` rewrite rule is needed).
